VELORA ROADS - Windows build

Run VeloraRoads.exe. Keep the "data" folder next to the exe (it holds the baked world).

Controls: W/S/A/D or arrows drive, Space handbrake, C camera, R reset to road,
Tab garage, ` console, F2 debug menu, M map (click = GPS waypoint), P photo mode,
L headlights, H horn, F3 hide HUD, F12 screenshot.
Races / time trial: stop inside the start gate to begin.
Saves: %APPDATA%\Godot\app_userdata\Velora Roads\velora_save.json
