# Ridgeline Festival

Игра, созданная Claude Opus 5.5 на уровне мышления **max** по одному промпту: открытый мир в духе Forza Horizon на движке Godot 4.7 с 3D-моделями из Blender.

## Как запустить

| Система | Что нажать |
|---|---|
| **Windows** | двойной клик по `PLAY-Windows.bat` |
| **macOS** | двойной клик по `PLAY-Mac.command` |

Первый запуск дольше остальных: скачивается движок Godot и подготавливаются файлы игры (2–10 минут). Дальше игра стартует сразу.
Подробная инструкция для новичков: [главный README](../README.md).

## Что здесь лежит

| Файл / папка | Что это |
|---|---|
| `OPUS_5.5_FINAL_REPORT.md` | итоговый отчёт агента: что сделано, что работает, время, токены, стоимость |
| `DEVELOPMENT.md` | как устроена игра, управление, карта, результаты тестов |
| `FEATURE_MATRIX.md` | честная таблица: что работает, что частично, чего нет |
| `RESEARCH_NOTES.md` | исследование Forza Horizon 5, которое агент сделал перед работой |
| `PROGRESS.md` | журнал работы агента |
| `Prompt_5_max.md` | промпт, по которому агент работал |
| `blender_source/` | исходный `.blend`-файл со всеми 3D-моделями |
| остальное | проект Godot: сцены, скрипты, ресурсы, 3D-модели |
