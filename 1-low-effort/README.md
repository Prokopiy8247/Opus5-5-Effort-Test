# Horizon Drift: Four Valleys

**English** | [Русский](#русский)

A game built by Claude Opus 5.5 at the **low** effort level from a single prompt: a Forza Horizon-style open world in Godot 4.7 with 3D models from Blender.

## How to run

| System | What to do |
|---|---|
| **Windows** | double-click `PLAY-Windows.bat` |
| **macOS** | double-click `PLAY-Mac.command` |

The first launch takes longer: the Godot engine is downloaded and the game files are prepared (2–10 minutes). After that the game starts right away.
Detailed beginner guide: [main README](../README.md).

## What's in here

| File / folder | What it is |
|---|---|
| `OPUS_5.5_FINAL_REPORT.md` | the agent's final report: what was done, what works, time, tokens, cost |
| `DEVELOPMENT.md` | how the game is built, controls, map, test results |
| `FEATURE_MATRIX.md` | an honest table: what works, what partly works, what is missing |
| `RESEARCH_NOTES.md` | the Forza Horizon 5 research the agent did before starting |
| `PROGRESS.md` | the agent's work log |
| `Prompt_1_low.md` | the prompt the agent worked from |
| `blender_source/` | the source `.blend` file with all 3D models |
| everything else | the Godot project: scenes, scripts, resources, 3D models |

# Horizon Drift: Four Valleys — Русский

[English](#horizon-drift-four-valleys) | **Русский**

Игра, созданная Claude Opus 5.5 на уровне мышления **low** по одному промпту: открытый мир в духе Forza Horizon на движке Godot 4.7 с 3D-моделями из Blender.

## Как запустить

| Система | Что нажать |
|---|---|
| **Windows** | двойной клик по `PLAY-Windows.bat` |
| **macOS** | двойной клик по `PLAY-Mac.command` |

Первый запуск дольше остальных: скачивается движок Godot и подготавливаются файлы игры (2–10 минут). Дальше игра стартует сразу.
Подробная инструкция для новичков: [главный README](../README.md).
